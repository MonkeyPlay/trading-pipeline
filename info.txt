This is an NQ futures opening-forecast pipeline (Interactive Brokers data collector →
feature/forecast engine → SQLite → NiceGUI dashboard).

See README.md for the full documentation. Quick orientation on what you can run:

1. The dashboard (view existing data/forecasts) — this is likely what "run" means
   day-to-day:

   source .venv/bin/activate
   python -m dashboard.app        # then open http://127.0.0.1:8080

2. The full daily pipeline (collects fresh IB data, runs forecast):

   ./scripts/run_pipeline.sh

3. To pull the latest data from IB Gateway into the DB, run the collector directly.
   This is step 1 of run_pipeline.sh — you don't need daily_forecast.py for just an
   update, that's the forecasting step:

   source .venv/bin/activate
   python3 -m collector.ib_collector --expiry 202609

   This requires IB Gateway/TWS running locally (port 4002 by default for paper
   trading, per config.py) and pulls 1-min bars via collector.ib_collector.

Worth knowing before you try either:

- .env is empty (0 bytes) — no OPENAI_API_KEY/ANTHROPIC_API_KEY set, so the forecaster
  falls back to its deterministic baseline instead of using an LLM.
- data/trading_pipeline.db exists and holds real collected bars. The databases, logs and
  .venv are gitignored, so a fresh clone starts empty — seed one with
  populate_mock_data.py --reset, or run the collector.
